## Why open source

Look around. Almost everything you touch was built in the open:

- **Linux** runs the internet — every cloud, every phone, every Mars helicopter.
- **Git** hosts this very page. It was given away, and in return it took over the world.
- **The web, compilers, languages, databases** — decades of shared infrastructure, donated by people who wanted the world to move faster.

Open source is the most successful idea-sharing experiment in human history. Nobody signed a contract to leave the code better than they found it — they just did. That's the world we want to live in, and the one we want to hand down.

**And now AI is writing software.** That makes openness matter *more*, not less. The more powerful the tool, the more it must be inspectable, forkable, and owned by the people who use it. Trust is not a feature you ship — it's a thing you build in public.

So: we publish everything. Our code, our decisions, our mistakes. Come read them.

## What we build

A lab for open-source tooling around AI coding agents — local-first software that keeps developers in charge.

| Project | What it is |
|---|---|
| **[pi-boat](https://github.com/ice-ai-lab/pi-boat)** | 🛥️ The boat that carries `pi` — a local AI coding assistant built on the pi-coding-agent SDK. **One core, many frontends**: browser today, desktop tomorrow. Your sessions, your models, your machine. |
| **[dsh-plugin-pi-ui](https://github.com/ice-ai-lab/dsh-plugin-pi-ui)** | Sidebar chrome for the DeepSeek Harness Web GUI — temporary sessions, working-directory picker, a draft composer that commits nothing until you send. |
| **[dsh-plugin-codex-ui](https://github.com/ice-ai-lab/dsh-plugin-codex-ui)** | Codex-style sidebar skin for the DeepSeek Harness Web GUI — Projects + Recents browsing that starts sessions without ceremony. |

## Principles

1. **Open by default.** Source, architecture decisions, and roadmaps live in public. A private repo is a last resort, not a habit.
2. **Local-first.** Your machine, your files, your credentials. Cloud is an option, never a requirement.
3. **Small, sharp tools.** Composable pieces beat monoliths. One good core, many thin frontends.
4. **Docs are code.** When docs and code disagree, that's a bug — fix it the same day.
5. **Good commits change the world.** Talk is cheap. Show the code.

## Contributing

The whole point of this org is that it's not just us.

- 🌱 **First open-source contribution?** We've all been there. Typos, docs, and small fixes are real contributions — open a PR, we'll help you through it.
- 🐛 Found a bug? Open an issue with repro steps; we treat good bug reports as gifts.
- 💡 Have an opinion about where a project should go? Issues are the right place to argue. Disagreement welcome, manners required.

> *"Talk is cheap. Show me the code."* — Linus Torvalds
